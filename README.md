## 🎮 About

**Space Raiders** is a 2D space-shooter developed in **C++** using the **Raylib** graphics library.

The game focuses on fast-paced combat, progressive difficulty, enemy scaling, level progression, boss encounters, and persistent game saves.

This repository contains the **Windows desktop version and its source code**.

---

## ✨ Features

### Combat
- Player-controlled space combat
- Multiple enemy types
- Elite enemies
- Boss encounters
- Enemy projectile systems
- Power-ups
- Increasing combat difficulty

### Progression
- Multi-level progression
- Progressive enemy scaling
- Procedurally generated level encounters
- Increasing challenge throughout the game
- Boss stages

### Save System
- Save and Resume functionality
- Persistent game state
- Checkpoint support
- Resume protection against applying level scaling twice

### Presentation
- Custom space-themed visuals
- Custom enemy, elite and boss designs
- Animated gameplay effects
- Dedicated main menu
- Game-over and level progression screens
- Fullscreen support
